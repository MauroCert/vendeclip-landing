# VendeClip landing website

The complete Next.js website is in `vendeclip-home/`. It is a regular directory, not a Git submodule.

```sh
cd vendeclip-home
npm ci
npm run dev
```

Run `npm run build` to generate the static site in `vendeclip-home/out/`.

The `output/` directory contains the fictional Villa Luma property photo and video kit, including its ZIP archive.

Dependencies, generated builds, local environment files, and Git metadata are excluded. See `vendeclip-home/README.md` and `vendeclip-home/docs/` for project details.
