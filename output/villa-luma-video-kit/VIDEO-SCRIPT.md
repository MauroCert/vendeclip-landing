# Villa Luma — video script

Use one language per video. This is a suggested 45–55 second edit: optional 5–7 second presenter opening, ten approximately 4-second property scenes, and a short closing card. Match the final timing to the actual generated speech.

## Optional presenter opening

**English:** “Hi, I'm Alex. Welcome to Villa Luma, a fictional home created for this VendeClip demo.”

**Español:** “Hola, soy Alex. Bienvenidos a Villa Luma, una casa ficticia creada para esta demo de VendeClip.”

Use `presenter/11-broker.png`. Alex Morgan is a fictional character; the portrait does not identify an actual broker.

## Short on-screen text

- Opening: “VILLA LUMA” / “Fictional property demo”
- Exterior or entry: “4 bedrooms · 3 bathrooms” / “4 dormitorios · 3 baños”
- Living room: “320 m² of interior space” / “320 m² interiores”
- Pool: “Private pool · 950 m² plot” / “Piscina privada · Terreno de 950 m²”
- Closing: “Create your next property video with VendeClip.” / “Creá el video de tu próxima propiedad con VendeClip.”
- Disclosure on closing card or caption: “AI-generated property and presenter · Fictional demo” / “Propiedad y presentador generados con IA · Demo ficticia”

The price is optional; leaving it out makes the demo more reusable. Do not add a real street address, phone number, brokerage logo, or a booking link for this invented property.
