## Website implementation

This is not a corporate partnership or integration claim. Country-specific customer affiliations were not supplied, so the section does not invent them.

## Research limits

The table distinguishes company-reported leadership from verified presence. There is no single comparable “biggest” metric across these markets. Unresolved rows are intentionally not assigned a winner. Campaign targeting and existing brand presets do not establish customer affiliation. Only the four owner-confirmed brands are used in the customer section.
